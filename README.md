# ReAppKit

[Türkçe](README.tr.md)

ReAppKit is an early-stage project for simplifying the setup of a Windows PC after a clean installation or a move to another computer.

The intended product is a terminal interface with two selection screens: one for applications and one for Windows and application settings.

## Current status

ReAppKit is in the planning stage. There is no working application or release yet, and no installation or usage instructions are available.
